# Memory Allocator

Реализация базового аллокатора памяти на языке C с использованием системных вызовов `mmap`/`munmap`. Проект демонстрирует ручное управление памятью на уровне страниц, выделение и освобождение блоков, а также включает набор тестов для проверки корректности работы.

---

## Функциональность

- Инициализация кучи фиксированного размера.
- Выделение памяти (`_malloc`) и освобождение (`_free`).
- Разделение больших свободных блоков (`split_if_too_big`).
- Слияние соседних свободных блоков (`try_merge_with_next`).
- Расширение кучи за счёт новых регионов памяти (`grow_heap`).
- Отладочный вывод структуры кучи (`debug_heap`, `debug_struct_info`).

---

## Архитектура

Аллокатор организован как односвязный список блоков памяти.  
Каждый блок описывается структурой `block_header`:

```c
struct block_header {
  struct block_header* next;      // указатель на следующий блок
  block_capacity capacity;        // размер области данных
  bool is_free;                   // флаг "свободен"
  uint8_t contents[];             // гибкий массив — начало данных
};
```

Регионы памяти выделяются с помощью `mmap` и выравниваются по размеру страницы.

---

## Основные функции

| Функция | Описание |
|--------|----------|
| `heap_init` | Инициализация кучи и выделение первого региона |
| `heap_term` | Полная очистка кучи, освобождение всех регионов |
| `_malloc` | Выделение блока памяти (публичный интерфейс) |
| `_free` | Освобождение блока с попыткой слияния |
| `memalloc` | Основная логика поиска/расширения блока |
| `try_memalloc_existing` | Поиск подходящего блока в существующей куче |
| `grow_heap` | Расширение кучи новым регионом |
| `split_if_too_big` | Разделение слишком большого блока |
| `try_merge_with_next` | Слияние со следующим блоком, если оба свободны |
| `debug_heap` | Вывод состояния кучи в файл |

## Сборка и тестирование

Проект использует CMake. Поддерживаются компиляторы **GCC**, **Clang** и **MSVC**.

### Сборка

```bash
mkdir build && cd build
cmake ..
cmake --build .
```

### Запуск тестов

```bash
ctest --output-on-failure
# или
make check
```

Тесты расположены в директории `tester/` и используют перехват системных вызовов `mmap` для проверки корректности работы аллокатора.
